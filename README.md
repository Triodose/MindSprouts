# MindSprouts（思芽）

Windows 桌面心智圖編輯器，沿用 Electron + React + TypeScript，支援離線使用。

## 使用方式

1. 啟動桌面程式，選擇儲存心智圖的工作目錄。
2. 從左側建立心智圖，變更會自動儲存；也可使用工具列儲存按鈕或 `Ctrl + S`。
3. 每張心智圖是一個 `.sprout` JSON 檔，分類對應工作目錄內的子資料夾。
4. 左側「工作目錄」標題右側的重新整理圖示可更新清單，齒輪圖示可選擇並切換工作目錄。程式會記住上次的工作目錄。已開啟的心智圖在本次工作目錄使用期間保留內容、畫布平移／縮放及復原紀錄，切換回來不重新載入或置中；手動重新整理、切換工作目錄或重新啟動後才重新載入。

不需要 Google 帳號、Google Drive API 或網站部署。使用者可以自行備份整個工作目錄。檔案若被外部修改，程式會阻止覆寫並顯示錯誤；可以另存副本或重新載入。刪除心智圖會移至系統資源回收筒。

## 複製與貼上節點

選取節點後按 `Ctrl + C`，會複製該節點與整個子分枝。切換到另一張心智圖，選取目的節點後按 `Ctrl + V`，分枝會貼上為該節點的子節點；也可使用工具列上的複製／貼上圖示。未選取節點時，貼到主根節點下。

保留文字、備註、標記、明確設定的樣式及分枝內的概要、外框與關聯線；每次貼上均產生新的 ID。連到複製範圍外的關聯線不會帶入。貼上支援復原／重做並自動儲存；文字編輯狀態下的 `Ctrl + C`／`Ctrl + V` 維持文字操作。

## 舊資料

新版介面不提供舊資料移轉按鈕。原有 `local.db` 保留；已移轉的工作目錄可直接選擇使用。原 Google Drive 的檔案請先自行下載，再透過匯入功能載入 `.sprout` 或 JSON 檔。

## 開發及打包

```sh
npm install
npm run electron:dev
```

製作 Windows 安裝檔：

```sh
npm run electron:dist
```

所有建置輸出固定放在 `dist/`；Windows 安裝檔直接位於此目錄，介面與桌面主程式分別放在固定的 `dist/renderer/`、`dist/electron/`，測試產物放在 `dist/tests/`。不建立其他命名的輸出目錄。正式版直接載入隨程式附帶的介面檔案，不啟動本地網頁伺服器。`npm run dev` 僅供介面開發，正式使用請啟動桌面程式。

## 驗證

```sh
npm run test:clipboard
npm run test:workspace
npm run test:desktop
npm run lint
```

檔案測試涵蓋讀回、改名、重名、分類、外部衝突、損壞及刪除失敗；桌面測試使用獨立暫存資料，檢查首次選目錄、新增心智圖、舊資料移轉、目錄切換及關閉存檔。

功能規格見 [docs/specifications.md](docs/specifications.md)。


## 專注畫布介面

正式介面採用 B「專注畫布」：左側窄版導覽列、浮動編輯工具列與獨立縮放列，左右側欄預設收起。心智圖清單支援搜尋；檔案匯入／匯出、關聯線、備註、語言與說明集中於「更多」選單。既有心智圖配色不變，新圖使用「專注薄荷」主題。

開發時執行 `npm run dev`，可在 `http://127.0.0.1:5189/?preview=focus` 使用範例資料體驗正式介面。此預覽僅保留記憶體資料，不讀取工作目錄，也不包含在正式版中。

原始三種 UI 設計原型保存在 `codex/interface-prototype` 分支，採用 B 的決策已整合至正式元件。
